Since version 16.0.0, the schema validation is provided as an optional secondary entry point. Import it from @oblique/oblique/schema-validation instead of @oblique/oblique.

Schema validation requires the ajv and ajv-formats packages. Because AJV generates code at runtime, the CSP must allow 'unsafe-eval'. This is an unavoidable security trade-off when schema validation is enabled.

To minimize the impact on security and performance, import the schema validation entry point only when actually needed.
